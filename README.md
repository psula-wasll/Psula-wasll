# خەرجی خانووەکان — ڕێنمایی دامەزراندن

ئەم ئەپە بۆ تۆمارکردنی پسوولە و پارەی وەرگیراوی خانووەکانە و ڕاپۆرتیش بە شێوەی PDF دەردەکات بۆ پرێنتکردن.

- **ئەپەکە** لەسەر GitHub Pages دادەنرێت و بێبەرامبەرە.
- **چوونەژوورەوە و داتاکان** لە Firebaseی Google پاشەکەوت دەکرێن و پلانی بێبەرامبەریشی بەسە.
- هەر هەژمارێک تەنها داتای خۆی دەبینێت.

دامەزراندن تەنها یەکجار دەکرێت و نزیکەی ١٥ خولەک دەخایەنێت. ئاسانترە لەسەر کۆمپیوتەر بیکەیت.

---

## بەشی یەکەم: Firebase (چوونەژوورەوە و پاشەکەوتکردن)

**١. دروستکردنی پرۆژە**
بڕۆ بۆ https://console.firebase.google.com و بە Gmailەکەت بچۆ ژوورەوە. پاشان **Create a project** دابگرە، ناوێکی بۆ بنووسە (بۆ نموونە `xanu`) و **Create** دابگرە. Google Analytics پێویست نییە.

**٢. چالاککردنی چوونەژوورەوە**
لە مێنیوی لای چەپ بڕۆ بۆ **Authentication**، پاشان **Get started** دابگرە.
- لە **Sign-in method**، **Email/Password** هەڵبژێرە، چالاکی بکە و **Save** دابگرە.
- **Add new provider** دابگرە و **Google** هەڵبژێرە. چالاکی بکە، Support email هەڵبژێرە و **Save** دابگرە.

**٣. دروستکردنی شوێنی پاشەکەوتکردن**
لە مێنیوی لای چەپ بڕۆ بۆ **Firestore Database** و **Create database** دابگرە.
- شوێنێک هەڵبژێرە (بۆ نموونە `eur3 (europe)`).
- **Start in production mode** هەڵبژێرە و **Create** دابگرە.
- بڕۆ بۆ تابی **Rules**، هەموو ناوەڕۆکەکەی بسڕەوە و ناوەڕۆکی فایلی `firestore.rules` لە شوێنی دابنێ. پاشان **Publish** دابگرە.

**٤. وەرگرتنی زانیارییەکانی پرۆژە**
ئایکۆنی ⚙ دابگرە، پاشان **Project settings** و دواتر **Your apps**. ئایکۆنی وێب `</>` هەڵبژێرە، ناوێک بنووسە و **Register app** دابگرە.
Firebase بەشێکی وەک ئەمە پیشان دەدات:
```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "xanu-xxxx.firebaseapp.com",
  ...
};
```
فایلی `firebase-config.js` بکەرەوە و بەهاکانی `PASTE_...` بەم بەهایانە بگۆڕە.

---

## بەشی دووەم: GitHub Pages (لینکی ئەپەکە)

**٥.** بڕۆ بۆ github.com و **New repository** دابگرە. ناوی بنێ `xanu`، **Public** هەڵبژێرە و **Create repository** دابگرە.

**٦.** **uploading an existing file** دابگرە و ئەم فایلانە ڕابکێشە ناوی:
`index.html`، `firebase-config.js`، `manifest.webmanifest`، `icon-192.png` و `icon-512.png`
پاشان **Commit changes** دابگرە.

**٧.** بڕۆ بۆ **Settings › Pages**. لە بەشی **Source**، **Deploy from a branch** هەڵبژێرە و لە **Branch**، `main` و `/ (root)` هەڵبژێرە. پاشان **Save** دابگرە.
دوای یەک دوو خولەک لینکەکە ئامادە دەبێت:
`https://ناوی-هەژمارەکەت.github.io/xanu/`

**٨. گرنگ:** لە Firebase بڕۆ بۆ **Authentication › Settings › Authorized domains**، **Add domain** دابگرە و `ناوی-هەژمارەکەت.github.io` بنووسە.
ئەگەر ئەمە نەکەیت، چوونەژوورەوە بە Gmail کار ناکات.

---

## بەشی سێیەم: بەکارهێنان

**٩.** لینکەکە لە مۆبایلی ئەو کەسە بکەرەوە کە ئەپەکە بەکاردەهێنێت. دەتوانێت بە **Gmail** بچێتە ژوورەوە، یان بە **ئیمەیڵ و پاسۆرد** هەژمارێکی نوێ دروست بکات.

**١٠. دانانی وەک ئەپ لەسەر شاشەی مۆبایل:**
- **iPhone:** لە Safari دوگمەی Share دابگرە و پاشان **Add to Home Screen**.
- **Android:** لە Chrome مێنیوی ⋮ بکەرەوە و پاشان **Add to Home screen** یان **Install app**.

---

## پرسیار و کێشەکان

- **«ئەم لینکە لە Firebase زیاد نەکراوە»:** هەنگاوی ٨ بکە.
- **«ئەم شێوازی چوونەژوورەوەیە چالاک نەکراوە»:** هەنگاوی ٢ بکە.
- **«Firestore ڕێگە نادات»:** هەنگاوی ٣ بکە و یاساکان Publish بکە.
- **لە iPhone و لە ئەپی سەر شاشە، چوونەژوورەوە بە Gmail نەکرێت:** ئیمەیڵ و پاسۆرد بەکاربهێنە، یان یەکجار لەناو Safariدا بچۆ ژوورەوە.
- **گۆڕینی ئەپەکە دواتر:** فایلە نوێیەکان دووبارە لە GitHub بار بکە. داتاکان ناسڕێنەوە، چونکە لە Firebaseن نەک لە GitHub.
- **ئایا کەسی تر داتاکانم دەبینێت؟** نەخێر. کۆدی ئەپەکە لە GitHub گشتییە، بەڵام داتاکان لە Firebaseن و هەر هەژمارێک تەنها داتای خۆی دەبینێت.
